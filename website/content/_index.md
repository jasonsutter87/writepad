    text: >-

faq:
  - q: Is it really free?
    a: >-
      Yes. Writing, versions, narration, dictation, Library, World, history and export to PDF, Markdown and plain text are all free, with no time limit and no account. Only the EPUB and MP3 audiobook exports are part of the one-time Publish unlock.
  - q: What do I get for the $5?
    a: >-
      Two exports for the finished book. **EPUB 3** with a title page, a table of contents and one file per chapter, and an **MP3 audiobook** with one track per chapter, read with your voices, speed and pronunciations. You pay once; there is no subscription.
  - q: If it's open source, why pay?
    a: >-
      The code is public so you can read it, trust it and contribute to it. The Publish unlock is how the project pays for itself while the rest stays free for everyone.
  - q: Does my writing leave my computer?
    a: >-
      No. Your vault is a folder on your disk, and narration and dictation run locally. The one exception is optional and off by default: *Polish with Claude* sends dictated text to Anthropic using your own API key.
  - q: Which computers does it run on?
    a: >-
      macOS (Apple Silicon and Intel) and Windows 10 and 11. The installers aren't code-signed yet, so the first launch needs one extra click; the [download page](/download/) shows how.
  - q: Do I need anything else installed?
    a: >-
      Only for narration, which needs Python 3.10 or later. Press **Listen** and choose **Set up narration**, and WRITEpad installs the voice engine and downloads the voices itself. PDF export uses Chrome, Edge, Brave or Chromium if one is installed.
  - q: Can I use my Obsidian vault?
    a: >-
      Yes. Any folder of Markdown works, and WRITEpad keeps its own data in a hidden `.writepad` folder inside it.
