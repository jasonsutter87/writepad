**Properties** are your own notes about a page, as name and value pairs: point of view, setting, a date, a status, the source verses for a retelling. They sit under the page title and are never exported with the book.

{{< shot "properties" "A page with POV and setting properties under its title" >}}

## Add one

Click **+ Property** (*Add to this page: verses, POV, setting, [[a note]]*). Type a name, press <kbd>Tab</kbd>, type the value and press <kbd>Enter</kbd>. Names you've used on other pages are suggested as you type, so the same field stays spelled the same way.

- **Click** a property to edit it. While editing, **×** removes it.
- <kbd>Esc</kbd> cancels an edit. Clicking away saves it.

## Link to notes and pages

Put a name in double square brackets to make a link:

- `[[Herbert White]]` links to that note in your vault.
- `[[The paw]]` links to a page in this manuscript.
- `[[The Monkey's Paw#The knocking]]` links to a page in any manuscript: its title, `#`, then the page.

Click a link to go there.

## Find pages by property

[Search](/docs/search/) looks in properties too. Search for a value, like a character's name or a place, and the pages tagged with it come up.

If a property holds book references like `Matthew 5:3–12`, searching for a reference finds every page whose references overlap it. So `Matthew 5:3` finds the page tagged `Matthew 5:3–12`.
