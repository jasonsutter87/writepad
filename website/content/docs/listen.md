Hearing a draft catches what reading it silently misses: clunky rhythm, repeated words, dialogue nobody would say. WRITEpad reads your work aloud with voices that run on your own computer. Nothing is sent anywhere to be read.

## Listen

Put the cursor where you want to start and click **▶ Listen** (<kbd>⌘↵</kbd>), or select a passage to hear just that. The sentence being read lights up as it goes. <kbd>Esc</kbd> stops.

Next to the button:

- the **narrator voice**,
- the **speed**, from 0.70× to 1.40×.

Lines in *italics* (a character's thoughts, say) are read in a second voice, which you pick in **Settings** under **Voice for *italic* lines**. **Pause after paragraphs** sets the gap between paragraphs.

## The first time: set up narration

The voices need a one-time setup on each computer. When WRITEpad asks, click **Set up narration**, or find it in **Settings**. It installs the voices (about 350 MB) and needs Python 3.10 or newer.

If your computer doesn't have Python yet, WRITEpad says so and walks you through it: **Get Python** opens python.org's download page, and after you've installed it, **Try again** carries on with the setup. On Windows, tick **Add python.exe to PATH** in the Python installer.

## Table reads for screenplays and dialogue

In a [screenplay](/docs/screenplays/), **▶ Listen** gives each character a voice, like a table read. The **Cast** panel on the right lists who reads which part; the narrator reads headings and action. Change any voice there, or click **Recast everyone** for a fresh mix.

## Pronunciations

Names like *Laburnam* or *Meggins*, or anything from your own invented world, can be taught once. In **Pronunciations** (on the right), type the word, then how to say it (respell it like `WER-bose`, or give IPA between slashes) and click **+**. Every voice uses it from then on. Click a word in the list to hear it.

## Compare two versions by ear

**A/B listen** in the [Onion skin](/docs/onion-skin/) panel plays the version you're comparing with, then the one you're on.

## Make an audiobook

[Export](/docs/export/) the book as an **MP3 audiobook**: one narrated file per chapter, with the cast's voices for a screenplay.
