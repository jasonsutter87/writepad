**Notes** are plain markdown files in your vault: research, ideas, outlines, anything that isn't the book itself. They work in any markdown editor, and the same folder can be an Obsidian vault at the same time.

## Write a note

On the **Notes** tab, click **New note** and give it a **Name**. A name with a slash, like `ideas/Unit 12`, puts the note in a folder. It opens ready to type, and saves as you go.

Click any note in the list to open it. **Delete note** (twice to confirm) moves it to the trash.

## Link notes together

Type a name in double square brackets, like `[[Herbert White]]`, to link to that note. Click the link to open it. If there's no note by that name yet, clicking it creates one.

A link can also point to a page in a manuscript: `[[The Monkey's Paw#The knocking]]`.

## Listen to a note

**▶ Listen** works on notes just as it does on pages.
