What it does

Built for the second draft, and the tenth.

Most editors keep the latest version and throw the rest away. WRITEpad keeps all of them side by side, so trying something is never a risk.

Versions, not overwrites

Every block holds a stack of takes. Fork one to try something; make the best one live. Nothing is lost by experimenting.

Onion skin

Lay any take over another. Words you added are tinted, words you cut stay as ghosts, and a slider fades them.

Cuts

Drag blocks to reorder the story, then save the order and the live takes as a named cut you can come back to.

Hear what you wrote

Local narration reads from the cursor, highlights each sentence, gives italics a second voice and learns your names' pronunciations.

Dictation

Hold Right Option and talk; let go and the words land at the cursor. Whisper runs on your machine.

Library and cadence

Measure the books you learn from, blend them into a target, and see where your sentences, chapters and dialogue drift from it.

World

Characters, places, things and a timeline as notes. Suggest finds the cast and locations in your manuscript, with no AI.

Screenplays

Write in Fountain with Tab to cycle elements, measure produced scripts, and line a book up against its film.

History

Snapshots are git commits in your vault. Restore an old paragraph as a new take, or roll the whole vault back.

Make it yours

Follow the system, or pick light, dark or a custom theme from five colours, with a warning if your text gets hard to read. Presets include Paper, Night, Ocean, Rose, Forest and Midnight.

Room for agents

A built-in MCP server lets AI agents read and write takes alongside you. Every take they make is labelled with their name.

Any folder of Markdown

Point it at a folder or an Obsidian vault; notes are plain .md files and wikilinks work. Import old drafts, an EPUB or a PDF and same-titled sections line up as versions.

Everything stays local

Your manuscript is a folder, not a cloud account.

  • Plain files. Notes are Markdown; an Obsidian vault works as-is. Takes are one .md file each.
  • Local voices. Narration runs Kokoro and dictation runs Whisper on your own machine.
  • Real history. Snapshots are git commits in your vault, readable by any git tool and pushable for backup.
  • Library keeps numbers only. Books you measure are reduced to statistics; their text is never stored.

Is it really free?
Yes. Writing, versions, narration, dictation, Library, World, history and export to PDF, Markdown and plain text are all free, with no time limit and no account. Only the EPUB and MP3 audiobook exports are part of the one-time Publish unlock.
What do I get for the $5?
Two exports for the finished book. EPUB 3 with a title page, a table of contents and one file per chapter, and an MP3 audiobook with one track per chapter, read with your voices, speed and pronunciations. You pay once; there is no subscription.
If it's open source, why pay?
The code is public so you can read it, trust it and contribute to it. The Publish unlock is how the project pays for itself while the rest stays free for everyone.
Does my writing leave my computer?
No. Your vault is a folder on your disk, and narration and dictation run locally. The one exception is optional and off by default: Polish with Claude sends dictated text to Anthropic using your own API key.
Which computers does it run on?
macOS (Apple Silicon and Intel) and Windows 10 and 11. The installers aren’t code-signed yet, so the first launch needs one extra click; the download page shows how.
Do I need anything else installed?
Only for narration, which needs Python 3.10 or later. Press Listen and choose Set up narration, and WRITEpad installs the voice engine and downloads the voices itself. PDF export uses Chrome, Edge, Brave or Chromium if one is installed.
Can I use my Obsidian vault?
Yes. Any folder of Markdown works, and WRITEpad keeps its own data in a hidden .writepad folder inside it.
