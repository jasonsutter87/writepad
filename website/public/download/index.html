First launch

The installers aren't code-signed yet, so your computer will ask once before opening them.

  • Mac: open WRITEpad once, then go to System Settings → Privacy & Security and click Open Anyway.
  • Windows: when SmartScreen appears, click More info → Run anyway.

Narration

Listening needs Python 3.10 or later. Press Listen and choose Set up narration; WRITEpad installs the Kokoro voice engine and downloads the voices itself. Everything else works without it.

Trying the demo

  1. Unzip WRITEpad-Demo-Vault.zip.
  2. In WRITEpad, open Settings and choose the unzipped folder as your vault.
  3. Open the note Start here.

Build it yourself

The source and build instructions for Mac and Windows are in the GitHub repository.
