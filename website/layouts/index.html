Everything stays local

Your manuscript is a folder, not a cloud account.

  • Plain files. Notes are Markdown; an Obsidian vault works as-is. Takes are one .md file each.
  • Local voices. Narration runs Kokoro and dictation runs Whisper on your own machine.
  • Real history. Snapshots are git commits in your vault, readable by any git tool and pushable for backup.
  • Library keeps numbers only. Books you measure are reduced to statistics; their text is never stored.
